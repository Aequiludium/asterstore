# 五分区变更规模检查

```bash
uv run --locked --extra polars python benchmarks/partition_scale.py --members 100 1000 10000
```

脚本仅使用临时目录，先生成指定历史规模，再更新相同五个分区。它记录路径检查次数、文件同步次数、控制目录遍历、变更记录字节数和发布时间。

对发布及回退验证操作计数不随历史分区数增长；检测访问未变化正式路径或遍历正式目录时直接失败。clean 的工作量可以随积累的失效事务材料增长，但不能遍历正式历史数据。

文件内容为小型合成字节。该基准验证管理操作规模，不代表实际 Parquet 吞吐、NFS 或断电资格验证。
