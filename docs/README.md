# 使用与维护文档

AsterStore 管理数据集中的文件版本。调用方负责生成数据、检查内容、协调读取与维护时间；仓库负责完整成员集的发布、回退和文件回收。

| --- | --- |
| 初始化仓库并完成首次发布 | [项目首页](../README.md) |
| 原路径接入已有文件、指定新文件位置 | [路径与归属](paths.md) |
| 增量更新、检查候选、处理提交异常、回退 | [发布与回退](publishing.md) |
| 固定版本读取、选择成员、使用 Polars | [读取](reading.md) |
| 预览和执行清理、理解读取寿命 | [清理](cleanup.md) |
| 查询参数、返回值和异常 | [API](api.md) |
| 理解职责、并发和空间成本 | [设计](design.md) |
| 检查磁盘布局和提交顺序 | [协议](protocol.md) |
| 开发与验证 | [贡献指南](../CONTRIBUTING.md)、[自动化](automation.md) |
| 构建与发行 | [发行流程](releasing.md) |

首次使用建议先运行临时目录示例，再阅读发布和清理文档。正式数据目录只能通过明确的初始化操作创建。
