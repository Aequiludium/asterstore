# 下一步与验收

首个真实应用数据集已完成[本地生命周期接入](aster-integration.md)。接下来发布 v0.1.0，保持单一实现和轻量读取边界。

1. 完成 PyPI Trusted Publisher 配置，运行完整发行验证，上传同一批制品。
2. Aster 消费端从锁定 Git 提交切换到发布的 PyPI 依赖，复验安装与集成。
3. 扩大数据日期、表数量和更新节奏，测量控制历史、并发和 GC 成本；另行评估因子治理替换与生产切换。

发布依赖图、Release/Pointer、deterministic 布局、元数据压缩、完整审计和共享挂载资格尚未交付；由实际需求决定顺序。应用可以把业务 JSON 作为普通对象与数据一起发布，不要求核心引入业务附件解码器。

PIT、字段质量、交易日、调度和历史目录适配仍属于应用侧；核心保持显式治理、固定计划与可恢复操作。
