# 当前范围与发行门槛

当前为 `0.1.0.dev1`，不是冻结候选。只有 Declaration/FileSet 模型、store 格式和一套生命周期实现。

已实现：registered 登记、资源根绑定、managed 写入、逻辑别名、同数据集复用、原子 current、固定请求恢复；metadata/objects 保留、条件释放、退役、固定计划回收及候选永久放弃和清理；可选 Polars。

已建立的验证包括：本地多进程冲突与终止恢复、权属隔离、完成态同步重试、外部数据无删除权、普通 current open 两份控制记录、绑定后零文件 I/O、真实 Parquet 延迟读取及回收、wheel/sdist 隔离安装。

尚不承诺：真实应用已经接入；NFS/共享挂载写入资格；真实断电验证；控制历史常数成本；发布依赖图；元数据压缩；完整审计。测试数量不能代替这些证据。

首版冻结之前，至少完成一个实际应用的完整数据生命周期接入，复核 API、格式及实际治理成本。发布操作再按[发行流程](releasing.md)执行。
