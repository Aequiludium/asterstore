# 0.1.0 范围与发行门槛

首版采用唯一 Declaration/FileSet 模型、store 格式和一套生命周期实现。

已实现：registered 登记、资源根绑定、managed 写入、逻辑别名、同数据集复用、原子 current、固定请求恢复；metadata/objects 保留、条件释放、退役、固定计划回收及候选永久放弃和清理；可选 Polars。

已建立的验证包括：本地多进程冲突与终止恢复、权属隔离、完成态同步重试、外部数据无删除权、普通 current open 两份控制记录、绑定后零文件 I/O、真实 Parquet 延迟读取及回收、wheel/sdist 隔离安装。

[Aster 首个真实数据集接入](aster-integration.md)已验证本地受管副本的完整生命周期，满足首版实际应用验收要求。它不表示整个 Aster 或生产目录已经迁移。

仍不承诺：NFS/共享挂载写入资格、真实断电、控制历史常数成本、发布依赖图、元数据压缩、完整审计和 Aster 全历史规模。测试数量不能代替这些证据。

PyPI v0.1.0 已通过完整 CI、发行检查和独立安装验收并正式发布；后续版本按[发行流程](releasing.md)执行。诊断接口的未发布增量见 CHANGELOG，不扩张本页的 0.1.0 保证。
