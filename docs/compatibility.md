# 开发阶段与格式边界

当前包版本为 `0.1.0.dev1`，尚未发布。撤回此前本地 rc1 的 API 冻结和开发格式兼容承诺；真实应用接入验证之后，再确定首版稳定范围。

运行时只实现一种声明模型和一种磁盘格式。仓库标记必须是 `kind: "store"`、`format_version: 1`，并满足完整的字段和必要功能约束。它不是早期开发草稿中同数字的 repository 格式。旧开发目录、未知版本、错误 kind、混合记录和未知必要功能均拒绝；没有旧读写器、兼容别名或自动迁移。

已存在的开发目录需要由调用方另建仓库、重新生成或显式登记原数据；库不会改写标记、接管权属或删除旧数据。registered 可以引用外部文件，但不因此取得其保留或删除权限。

当前只维护当前实现。尚未发布阶段允许直接改进 API 和持久结构，并记录破坏性变更；不为每次设计迭代保留历史运行时。格式标记和严格解码继续用于防止误读，并不表示已经历多个正式协议世代。

CI 验证当前 Schema、codec、正反样例和生命周期行为，不再用旧导出/签名快照阻止收敛。正式兼容承诺须以实际发布的版本和接入证据为依据。
