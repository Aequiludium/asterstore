# 目录与路径

`repo.create_dataset(name, path)` 在指定空目录建立数据集。目录可以位于登记目录之外，不同数据集可以位于不同文件系统；每个数据集的正式文件与其隐藏控制目录必须在同一文件系统。

仓库和数据集根目录、以及它们的父目录可以是软链接。例如 `Repository(Path.home() / "AsterStore")` 可以直接使用指向实际存储目录的入口。入口解析为真实绝对路径，数据集登记保存真实路径；不会移动数据、修改或删除软链接。尚不存在的目标目录仍遵循空目录初始化规则。

解析只发生在入口：已有对象与数据集登记不会因入口软链接改向而跟随到另一目录。已登记的真实目录若被替换为软链接，打开登记或操作已有对象会拒绝，而不是静默改向。

数据集目录独占、不可重叠。核心在登记时按真实路径检查边界，不同软链接不能绕过重复或父子目录冲突检查，日常发布不扫描其他数据集。一个部署使用统一登记目录；不同仓库并发登记同一目录树不受支持。

`batch.stage("date=2026-10-14/data.parquet")` 返回控制目录下的暂存文件，提交时安装到数据集根目录下的相同相对路径。文件名、目录层级、一天多少文件均由调用方决定。

多文件分区替换必须显式 stage 新文件、delete 过期文件。目录扫描不能推断业务上的替换范围。

不接受绝对数据路径、越界、空组件、反斜线、控制目录、数据集内部的软链接和非普通文件。新旧文件不得通过硬链接跨数据集共享。不能绕过事务原地修改正式文件。

部署使用空目录初始化，再生产数据。已有格式不会被自动升级。
